# VerificationOption

Determines the verification option to use for the account registration (Enum: SMS, EMAIL, CALL, INVOICE).

## Example Usage

```python
from shippo.models.components import VerificationOption

value = VerificationOption.SMS
```


## Values

| Name      | Value     |
| --------- | --------- |
| `SMS`     | SMS       |
| `EMAIL`   | EMAIL     |
| `CALL`    | CALL      |
| `INVOICE` | INVOICE   |
